# Contributing

Contributions should improve the research workflow without adding investment recommendations.

Before you open a pull request:

- keep the prompts tool-neutral;
- label synthetic examples clearly;
- use direct primary-source links for real examples;
- include publication and evidence dates;
- separate evidence from inference;
- do not include credentials, private data, or material non-public information;
- do not copy EquityLayer private product code or paid research packs.
