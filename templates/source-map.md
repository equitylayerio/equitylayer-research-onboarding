# Source map

Define the source policy before collecting evidence.

| Research need | Preferred primary source | Accepted secondary source | Not sufficient alone | Review frequency |
| --- | --- | --- | --- | --- |
| Company financial result |  |  | Search snippet, unsourced summary |  |

| Customer or supplier relationship |  |  | Logo page, rumor, inferred adjacency |  |
| Market or industry total |  |  | Undated chart |  |
| Regulation or policy |  |  | Commentary without the official text |  |

## Escalation rules

- Stop and ask for human approval when two primary sources conflict.
- Do not replace an accepted source artifact without recording the correction lineage.
- Flag a claim as stale when it is outside its declared freshness window.
- Record access limits, language limits, and missing fields.
- Do not use private or material non-public information.
